# 网页登录与个人资料接入

当前版本 `V1.0.0`。

## 页面和接口

| 页面 | 调用的接口 | 页面行为 |
| --- | --- | --- |
| `/` | [查询会话](../backend-api/auth/session.md)、[读取资料](../backend-api/profile/get-profile.md)、[退出登录](../backend-api/auth/logout.md) | 未登录进入登录页，资料未填写进入资料页。已填写则显示资料，提供编辑和退出入口。 |
| `/login` | [查询会话](../backend-api/auth/session.md)、[登录](../backend-api/auth/login.md) | 根据登录结果和 `profileReady` 进入资料页或首页。密码错误时显示原因并允许重试。 |
| `/profile` | [读取资料](../backend-api/profile/get-profile.md)、[保存资料](../backend-api/profile/save-profile.md) | 首次填写时使用空表单。编辑时预填现有基本资料，并保留选填字段。保存成功后进入首页。 |

## 会话与错误处理

- 网页向同源的 `/api/v1/…` 发请求。Next.js 转发到 Spring Boot，浏览器管理 `HttpOnly` 会话 Cookie。登录、保存和退出带上 `X-AI-Manager-Request: 1`。
- 未登录或会话失效时回到登录页。资料校验错误显示在对应输入框附近，用户可以保留输入继续修改。
- 保存发生版本冲突时，保留用户填写的内容。点击「读取最新资料」后，页面显示当前记录并使用最新版本和选填字段。再次点击保存才提交。

## 本机联调

先启动连接 MySQL 的 Spring Boot。前端通过 `AI_MANAGER_BACKEND_URL` 设置后端地址，默认使用 `http://127.0.0.1:8080`。后端运行在其他端口时，在启动开发服务或执行生产构建前设置这个变量。

```powershell
Set-Location 'D:\XK\chatGPT\AI_manager\frontend'
$env:AI_MANAGER_BACKEND_URL = 'http://127.0.0.1:8083'
npm.cmd run dev -- --port 3001
```

打开 http://127.0.0.1:3001，用应用主人账号登录。已有资料的账号可以验证首页、刷新、编辑和退出。首次填写使用空资料的隔离测试环境。
