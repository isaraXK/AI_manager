# 健康检查

- 当前版本 `V1.0.0`
- 接口 `GET /actuator/health`
- 验证状态：已在本机验证普通配置和 smoke 配置均返回 `UP`。

检查后端是否启动并返回健康状态。

## 请求

无请求体，无需登录 Cookie。该端点使用后端地址和端口。

## 响应

健康时返回 HTTP 200。

```json
{"status":"UP"}
```

当前配置只展示汇总状态。使用 smoke 配置时数据源和 Flyway 已禁用，`UP` 表示后端可响应。验证 MySQL 时应使用普通配置启动并检查连接日志。
